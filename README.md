**# Online Purchase Prediction**



**Predicts whether an online shopping session will result in a purchase, using an ensemble of Random Forest, XGBoost, and CatBoost.**



**## Dataset**

**UCI Online Shoppers Purchasing Intention Dataset**



**## Setup**

**python -m venv venv**

**venv\\Scripts\\activate**

**pip install -r requirements.txt**



**## Structure**

**- notebooks/ — EDA and modeling notebooks**

**- src/ — reusable pipeline code**

**- backend/ — FastAPI serving app**

**- frontend/ — UI**
